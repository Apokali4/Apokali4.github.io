# Экзамен ПМ 02

Android-оболочка для исходного автономного теста. Исходный HTML встроен как локальный asset без изменения содержимого. Вопросы, ответы, изображения и логика теста остаются такими, как в исходнике.

Сборка: Gradle 8.9, JDK 17, Android SDK 35.
Команда из каталога PM02Exam: gradle assembleDebug.
APK: app/build/outputs/apk/debug/app-debug.apk.
